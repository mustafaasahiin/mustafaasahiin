## About

I build apps that make everyday tasks easier and tools that remove friction from development. I compete in shipatons and hackathons, where choosing the right scope matters as much as writing the code.

I'm drawn to practical problems: repetitive workflows, disconnected tools, and ideas that need a clear path to a usable first release. I work across languages and platforms, choosing the stack around the product and its constraints.
